# 验证指南 - 自动购买功能

## 验证步骤

### 1. 安装依赖

```bash
cd /home/reggie/vscode_folder/GLM

# 安装 Python 依赖
pip install -r requirements.txt

# 安装 Playwright 浏览器
playwright install chromium
```

### 2. 分析目标页面

首先，让我们看看实际的页面结构：

```bash
python test_browser.py analyze
```

这会打开浏览器并访问目标页面。请记录以下信息：

**需要确认的选择器：**
- 商品名称元素的 class 或 id
- 库存状态显示元素的 class 或 id
- 购买按钮的 class 或 id
- 登录框（如需要）

### 3. 调整页面解析器

根据分析结果，编辑 `bot/pages/bigmodel.py`：

```python
async def check_stock(self, product_selector: str = "这里替换为真实选择器"):
    # ...
```

```python
async def purchase(self, timeout: int = 30000):
    # 更新以下选择器
    await self.navigator.click("这里替换为购买按钮选择器")
    await self.navigator.click("这里替换为确认按钮选择器")
    success = await self.navigator.is_visible("这里替换为成功提示选择器")
```

### 4. 测试库存检查

```bash
python test_browser.py check-stock
```

检查能否正确获取库存状态。

### 5. 测试购买流程

```bash
python test_browser.py test-purchase
```

### 6. 使用 API 进行完整测试

1. 启动服务：
```bash
docker-compose up -d
```

2. 访问 API 文档：
http://localhost:8000/docs

3. 创建监控任务：
```bash
curl -X POST http://localhost:8000/api/v1/monitor/tasks \
  -H "Content-Type: application/json" \
  -d '{
    "name": "My Monitor",
    "target_url": "https://bigmodel.cn/glm-coding",
    "check_interval": 30,
    "auto_purchase": false
  }'
```

4. 启动任务，观察日志

## 常见问题

**Q: 浏览器看不到页面？**
A: 在 `.env` 中设置 `PLAYWRIGHT_HEADLESS=false`

**Q: 找不到元素？**
A: 使用 `test_browser.py analyze` 检查实际页面结构

**Q: 怎么调试？**
A: 查看 `data/screenshots/` 中的截图，或者在开发模式下运行
